Thực hành: Clone dự án từ Git

Kho nguồn được clone và kiểm tra trên máy. Log dưới đây được lấy từ các lệnh Git thực tế.

Clone: git clone https://github.com/codegym-vn/wf-hello.git

$ git remote -v
origin	https://github.com/codegym-vn/wf-hello.git (fetch)
origin	https://github.com/codegym-vn/wf-hello.git (push)

$ git log -1 --oneline
ce2374c Update README.md

$ git status
On branch master
Your branch is up to date with 'origin/master'.

nothing to commit, working tree clean

Các tệp: hello.txt
README.md
